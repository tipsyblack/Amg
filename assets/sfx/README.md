# Присланные звуковые эффекты

Сюда кладутся ЗАПИСАННЫЕ звуки — вуши, ризеры, клики. Готовит их для ролика
`npm run sfx:import`: приводит к моно 44.1 кГц wav, срезает тишину в начале,
обрезает слишком длинный хвост, выравнивает громкость и кладёт результат в
`public/sfx`.

Сами файлы в репозиторий не попадают — ни исходники отсюда, ни готовые wav.
Причина простая: репозиторий публичный, а права на эти записи принадлежат тем,
кто их сделал. Пользоваться ими в роликах и раздавать файлы из публичного git —
разные вещи, и на второе разрешения у нас нет. Синтезированные звуки
(`scripts/build-sfx.mjs`) лежат в репозитории как раз потому, что там
лицензировать нечего.

Отсюда следует: **на новой машине звуки надо принести заново**. Пока их нет,
ролик собирается на синтезированных заменах — см. `resolveSfx` в
`src/remotion/transitions.ts`.

## Как добавить свой звук

1. Положить файл сюда под именем из таблицы ниже (`swoosh.mp3` и т. д.).
2. `npm run sfx:import` — он напечатает длину, положение пика и громкость.
3. Если положение пика изменилось, поправить `SFX_LEAD_MS` в
   `src/remotion/transitions.ts`. `npm run test:timing` это проверяет и не даст
   таблице разойтись с файлами.

## Что за имена

| файл | где звучит |
|---|---|
| `swoosh.mp3` | наезд кадра, перебор карточек |
| `swoosh-air.mp3` | шторка — светлый, без низа |
| `swoosh-deep.mp3` | крупный разворот — тяжёлый, с низом |
| `swoosh-wood.mp3` | рваная шторка — сухой, деревянный |
| `swoosh-long.mp3` | выезд брендовой концовки |
| `riser.mp3` | подъём (пока не подключён, есть синтезированный `hook`) |
| `ding.mp3` | уведомление (пока не подключён, у объекта играет `pop`) |
| `mouse.mp3` | клик мышью (пока не подключён) |

## Про громкость

Уровень меряется по самому громкому окну 300 мс, а не по всему файлу: у
протяжного вуша RMS по файлу размазывается тишиной, и подгонка под него загнала
бы звук в клиппинг.

Подъём при этом ограничен запасом до потолка. У резких звуков (клик мыши)
крест-фактор большой по природе — короткий пик и почти ничего вокруг, — и до
общего уровня они не дотягивают. Это не ошибка импорта: такой звук просто не
может быть громким по RMS, и лучше оставить его тише, чем расплющить лимитером.
`sfx:import` печатает, сколько не добрал и почему.
