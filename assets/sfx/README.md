# Присланные звуковые эффекты

Здесь лежат ЗАПИСАННЫЕ звуки — вуши, ризеры, клики — в том виде, в каком их
принесли. Готовит их для ролика `npm run sfx:import`: приводит к моно 44.1 кГц
wav, срезает тишину в начале, обрезает слишком длинный хвост, выравнивает
громкость и кладёт результат в `public/sfx`.

И исходники, и готовые wav лежат в репозитории. Значит на новой машине импорт
запускать не нужно — всё уже на месте; он нужен только когда добавляют или
заменяют звук.

## Происхождение и права

Звуки принесены владельцем проекта; он же отвечает за право ими пользоваться и
за то, что они лежат в публичном репозитории. Исходные имена файлов сохранены
ниже: по ним видно автора и номер записи в стоке, откуда они скачаны — это
единственный след происхождения, который у нас есть, и терять его не стоит.
Хеш нужен, чтобы отличить «тот же файл» от «похожего».

## Как добавить или заменить звук

1. Положить файл сюда под именем из таблицы (или под новым — тогда его надо
   добавить в `SOURCES` в `scripts/import-sfx.mjs` и в `SfxName`).
2. `npm run sfx:import` — он напечатает длину, положение пика и громкость.
3. Если положение пика изменилось, поправить `SFX_LEAD_MS` в
   `src/remotion/transitions.ts`. `npm run test:timing` это проверяет и не даст
   таблице разойтись с файлами.
4. Записать происхождение нового файла в таблицу выше.

## Про громкость

Уровень меряется по самому громкому окну 300 мс, а не по всему файлу: у
протяжного вуша RMS по файлу размазывается тишиной, и подгонка под него загнала
бы звук в клиппинг.

Подъём при этом ограничен запасом до потолка. У резких звуков (клик мыши)
крест-фактор большой по природе — короткий пик и почти ничего вокруг, — и до
общего уровня они не дотягивают. Это не ошибка импорта: такой звук просто не
может быть громким по RMS, и лучше оставить его тише, чем расплющить лимитером.
`sfx:import` печатает, сколько не добрал и почему.
