# Фоновая музыка

Проще всего наполнить библиотеку командой **`/music`** в боте: она предлагает
7 настроений и генерирует инструментальный трек через Kie.ai (Suno), сразу
складывая его сюда.

Можно и вручную: положите свои файлы (`.mp3`, `.wav`, `.m4a`, `.ogg`) — при
сборке ролика будет выбран случайный и подмешан фоном (тихо, на 12%
громкости, с зацикливанием на всю длину видео).

Если папка пуста — ролик собирается без музыки.

Сами треки в git не попадают (см. `.gitignore`): кладите их прямо на
сервере, автодеплой их не тронет. Используйте только музыку, на которую у
вас есть права (для соцсетей это важно — ролик могут заглушить или
заблокировать за чужой трек).
