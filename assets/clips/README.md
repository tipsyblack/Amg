# Библиотека клипов с маскотом

Сюда `npm run clips:build` складывает десять коротких клипов с Шамилем —
появления, реакции, показы и прощания. Они генерируются **один раз** и дальше
подставляются в ролики бесплатно: маскот делает в любом видео одно и то же, и
платить за это каждый раз незачем.

Сами файлы в репозиторий не кладутся (см. `.gitignore`) — это десяток
видеофайлов, а собрать их заново можно одной командой.

```bash
npm run clips:build                       # сгенерировать недостающие
npm run clips:build -- --force            # пересобрать всё
npm run clips:build -- intro-lamp         # только один
```

Из чата то же самое делает `/library build`, а `/library` показывает, что уже
готово. Список клипов и их промпты — в `src/pipeline/clipLibrary.ts`.
