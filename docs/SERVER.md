# Запуск на выделенном сервере (Ubuntu/Debian)

Инструкция простым языком: как поставить проект на сервер и генерировать
ролики оттуда, не занимая свой компьютер.

## Что понадобится

- Выделенный сервер с Ubuntu или Debian и доступом по SSH.
- Ключи: OpenRouter (сценарий + картинки) и ElevenLabs (озвучка).
- Примерно 3 ГБ свободного места (Node.js, зависимости, headless Chrome).

## Шаг 1. Подключиться к серверу

С вашего компьютера, в терминале:

```bash
ssh пользователь@айпи-сервера
```

Например: `ssh root@203.0.113.10`. Пользователя и IP выдал хостинг при
покупке сервера.

## Шаг 2. Скачать проект

Репозиторий публичный, поэтому никакие токены и ключи для этого не нужны:

```bash
git clone https://github.com/tipsyblack/Amg.git
cd Amg
```

Если нужная ветка не открылась сама:

```bash
git checkout claude/remotion-video-automation-biby8g
```

## Шаг 3. Установить всё одной командой

```bash
sudo bash scripts/setup-server.sh
```

Скрипт сам поставит Node.js 22, зависимости проекта и системные библиотеки,
без которых Remotion не сможет рендерить видео. Занимает несколько минут.

## Шаг 4. Вписать ключи

Скрипт уже создал файл `.env`. Откройте его и заполните:

```bash
nano .env
```

Заполнить нужно три строки:

```
OPENROUTER_API_KEY=ваш_ключ_openrouter
ELEVENLABS_API_KEY=ваш_ключ_elevenlabs
ELEVENLABS_VOICE_ID=id_голоса_из_elevenlabs
```

Сохранить в nano: `Ctrl+O`, `Enter`, затем `Ctrl+X`.

`ELEVENLABS_VOICE_ID` берётся в кабинете ElevenLabs: раздел с голосами →
выбрать голос → скопировать его Voice ID.

Файл `.env` в git не попадает (он в `.gitignore`), так что ключи не утекут
в публичный репозиторий. Но на самом сервере это обычный файл — держите
доступ к серверу закрытым.

## Шаг 5. Сгенерировать ролик

```bash
npm run generate -- "бриф: что за продукт, для кого, какой посыл"
npm run render
```

Первая команда напишет сценарий, озвучит его и нарисует картинки к сценам.
Вторая — соберёт из этого видео. Готовый файл: `out/video.mp4`.

При первом рендере Remotion докачает headless Chrome (~150 МБ) — это
нормально, происходит один раз.

## Шаг 6. Забрать видео с сервера

С **вашего** компьютера (не с сервера):

```bash
scp пользователь@айпи-сервера:~/Amg/out/video.mp4 .
```

Файл окажется в текущей папке на вашем компьютере.

## Если что-то пошло не так

**`npm run generate` падает с ошибкой 401 или 403**
Ключ неверный или закончились деньги на балансе. Проверьте ключи в `.env` и
баланс в кабинете OpenRouter / ElevenLabs.

**`npm run generate` пишет, что модель не вернула изображение**
Модель в `OPENROUTER_IMAGE_MODEL` не умеет генерировать картинки или больше
недоступна. Актуальный список — на openrouter.ai/models, выбирать нужно
модель с поддержкой генерации изображений.

**Рендер падает с ошибкой про библиотеки или Chrome**
Скорее всего не хватает системной библиотеки. Запустите скрипт установки
ещё раз: `sudo bash scripts/setup-server.sh`.

**Рендер падает из-за нехватки памяти**
Уменьшите параллельность рендера:

```bash
npx remotion render src/remotion/index.ts VideoComposition out/video.mp4 \
  --props=data/video-data.json --concurrency=1
```

**Хочется обновить проект после моих правок**

```bash
cd ~/Amg
git pull
npm ci
```

## Про автоматический запуск по расписанию

Пока сознательно не настроено: сначала стоит убедиться, что стиль роликов
вас устраивает. Автогенерация без присмотра тратит деньги на API-запросы
при каждом запуске. Когда результат станет предсказуемым — добавим
cron-задание.
